# website

The product page from the time GetMyFilesBack was sold as "Bit Back" (bitback.org) - an unfinished draft,
kept as the starting point for a new page. **Not ready to publish**: its text still describes the old 32-bit
wizard for Windows XP-8, it has placeholder text and made-up reviews, the Terms of Use are a template from
another business, and the Buy button and the contact form don't do anything.

Open `index.html` in a browser to see it. Everything is local except the Lato font (Google Fonts), the Vimeo
video, and three form icons in `css/style.css` that are loaded from another site (rexkirby.com).

## Files

- `index.html` - the whole page; the Info, Company, Terms and Contact boxes are hidden `<div>`s in it
- `css/style.css`, `css/slider.css` - the page's own styles
- `img/` - its images
- `js/scroll-nav.js` - smooth scrolling to the page's sections
