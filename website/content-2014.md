# Text from the 2014 site

The marketing copy of the last version of the Bit Back site (October 2014), kept as the starting point for the
new page's text. Not ready to use as it is: it describes the old app (a three-step wizard, Windows XP-8, NTFS
only). Notes in *italics* say what has to change. The site's Terms of Use (a brokerage template), its ClickBank
store, the made-up reviews and the purchase scripts were not kept.

## Hero

**RECOVER YOUR DATA**
Undelete your pictures, videos and files in three simple steps.

*Now: one window - pick a drive, the deleted files appear while it is scanned, tick the ones you want, Recover.*

## About

**Get your Files back!**
**USER FRIENDLY DATA RECOVERY SOFTWARE**

If you've accidentally deleted your pictures, video clips, documents or any other file on your computer, BitBack
will get them BACK for you. BitBack will find the files you've deleted, undelete them and put them where ever you
want them. It only takes a couple of clicks and THREE easy steps.

## How does it work?

FROM WHERE - Choose the source drive
TO WHERE - Choose the destination
WHAT - Select the files that you want back

*The steps are the old wizard's - see the hero note.*

When a file is deleted, it's not completely deleted from the Hard drive. Windows only marks the place where the
file used to be as "free to write" and uses the space later. Until you write something there it is possible for
BitBack to get the files back for you.

*Still true, and the most useful paragraph here. Add: so stop using the drive, and don't save the recovered files
onto it - the app now warns about that.*

## Features

Icons: `img/feature-photos.png`, `feature-videos.png`, `feature-documents.png`, `feature-portable.png` (in this order).

**Photo Recovery** - BitBack Recovery tool recovers your deleted pictures easily, fast and without any damage to
your original file.

**Video Recovery** - BitBack Recovery tool recovers your deleted video and audio files in all formats and extensions.

**Document Recovery** - BitBack Recovery tool recovers your deleted documents, project's worksheets, pdf files and
all your data in few steps.

**Portable Tool** - BitBack Recovery tool is a user friendly portable software that is optimized to work on all
Windows operating systems.

*"Without any damage", "all formats", "all Windows" promise too much: overwritten files can't come back, and the app
is for 64-bit Windows 10/11. New features worth a line: NTFS, FAT and exFAT (USB sticks, SD cards), the
recoverability of every file before you recover it, the content check, the preview, the original folders and
dates.*

- Run absolutely safely. Safety was one of the main concerns while making this software.
- Get the original file names back - Windows mangles filenames when it deletes them.

*Dropped from the 2014 list: Windows 8/7/Vista/XP, "unlimited file sizes", "absolutely all file types" and
"multithreaded" (true, but not a reason to buy). "Absolutely safely": say what it means - the app only reads the
drive it scans.*

## Company (the "Company" box)

Bit Back is a user friendly software developed by ASOLUTIONS Software Organisation (ASO). The software was first
developed in 2008 in Germany, under the working title RODE 1.0, as a non-commercial tool for digital forensics and
data recovery. In 2009 a test version was released for commercial use, and after three years of improvement the
"Get my Files back" project became the user friendly software Bit Back.

*Shortened and corrected from the 2014 text. Check the facts before publishing.*
